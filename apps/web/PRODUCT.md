# Product

## Register

product

## Users

Studio owners, project managers, and account managers at web studios and digital agencies (5–30 person teams). They use StreamLine during active project execution: checking project health before client calls, reviewing pending approvals, and tracking deliverable status across multiple concurrent engagements. Clients access only the portal — a separate, simplified surface outside the studio dashboard.

## Product Purpose

StreamLine is the operational command center for web studios — replacing fragmented email threads, shared spreadsheets, and Notion docs with a single source of truth for client projects, milestones, deliverables, and approvals. The AI Proposal Generator is the differentiator: it collapses hours of proposal writing into minutes with real streaming output. Success looks like a studio owner who can walk a client through live project status in under 30 seconds and close a new project with a polished proposal in under 10 minutes.

## Brand Personality

Sharp, Efficient, Professional — Linear.app and Vercel Dashboard energy. Every element earns its place. Nothing decorates; everything informs.

## Anti-references

- **Generic purple SaaS**: heavy violet accent used indiscriminately across the UI without identity — looks like it was assembled from a Tailwind starter. The violet must mark action and meaningful status, not fill visual gaps.
- **Overly playful startup**: pastel palettes, rounded blobs, emoji-first communication, friendly-casual copy. The studio's clients judge the studio's taste by looking at the tools they use.

## Design Principles

1. **Violet earns its place** — Brand color marks interactive elements and critical status signals only. If it isn't a CTA, a live status badge, or an active state, it should not be violet.
2. **Density without crowding** — The dashboard shows what matters now, not everything that exists. Show the 3 active projects, not the full archive. Surface the number that requires action, not all numbers.
3. **Speed is perceived before it is measured** — Skeleton states load immediately. Transitions are exponential-eased and under 350ms. The tool must feel fast on first render, before any data arrives.
4. **Studio-grade credibility** — The dashboard is demoed to clients on calls. It must look like the studio built it themselves — confident typography, restrained color, no visual clutter that reads as "SaaS template."
5. **Signal over decoration** — A muted color means completed or inactive. A saturated color means it needs attention. The semantic color system must never use saturated hues decoratively.

## Accessibility & Inclusion

WCAG 2.1 AA. 4.5:1 contrast ratio for all body text and interactive elements, 3:1 for large text and UI components. Full keyboard navigation with visible focus states. `prefers-reduced-motion` respected on all Framer Motion animations (crossfade fallback). Semantic HTML structure throughout.
